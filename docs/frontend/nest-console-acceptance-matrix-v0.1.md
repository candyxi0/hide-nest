## 3. 治理动作矩阵

| ID | 场景 | 必须观察到 | 失败关闭 |
|---|---|---|---|
| GOV-01 | 归档 | 退出普通检索、可恢复 | 409 STALE 时不更新本地状态 |
| GOV-02 | 恢复 ACTIVE | 不自动解除隔离、不扩权 | 旧 policy 不复活 |
| GOV-03 | 隔离 | 普通检索／ContextPack 立即拒绝 | 异步清理失败仍保持围栏 |
| GOV-04 | 隔离恢复预览 | 按当前 policy 计算影响 | 旧 Token／旧 ContextPack 不复活 |
| GOV-05 | 删除影响预览 | 闭合范围、共享 Payload、灾备边界 | preview 不执行删除 |
| GOV-06 | 删除最终确认 | 一次不可撤销确认，随后只报告真实阶段 | 不提供取消或重新打开 |
| GOV-07 | 删除失败 | FINAL_FAILED 和仍隔离 | 不显示“已删除完成” |
| GOV-08 | 已投递后撤权 | 明说当前房间可能仍含旧文字 | 不承诺远程擦除当前窗口 |
| GOV-09 | 修正 | 返回 Codex 对话形成新 revision | 页面原地覆盖规范正文 |
| GOV-10 | 重复请求 | 使用稳定 idempotency key | 不重复执行副作用 |

## 4. 通用状态矩阵

| ID | 状态 | 页面行为 |
|---|---|---|
| ST-01 | loading | 保留稳定骨架和上下文，不显示假数据 |
| ST-02 | empty | 说明真的没有结果及下一步，不等同于故障 |
| ST-03 | denied | 不泄露对象是否存在 |
| ST-04 | stale | 停止旧操作，要求读取当前 revision |
| ST-05 | 410 expired | 说明临时资源过期，回到安全入口 |
| ST-06 | offline | 只读缓存标为陈旧，所有写动作关闭 |
| ST-07 | 5xx | 说明“读不到”而不是“没有记忆” |
| ST-08 | partial index | 明确规范已保存、检索仍在追赶 |

## 5. 本地 Adapter 安全矩阵

| ID | 检查 | 通过条件 |
|---|---|---|
| SEC-01 | 绑定地址 | 只监听 `127.0.0.1`／`::1`，不监听 LAN |
| SEC-02 | Host／Origin | 非许可值失败关闭 |
| SEC-03 | 启动 nonce | 页面启动会话绑定，过期／复用拒绝 |
| SEC-04 | 远端凭据 | 浏览器网络、JS、DOM、Storage、日志均不可见 |
| SEC-05 | CSP | 禁止远程脚本、内联执行和任意连接 |
| SEC-06 | 缓存 | 详情、证据、治理响应 `no-store` |
| SEC-07 | 日志 | prompt、回答、证据、工具参数、Token、对象正文零命中 |
| SEC-08 | 退出 | 关闭控制台使本地会话失效，不改变远端规范状态 |

## 7. 人类验收脚本

小林不需要读代码，只完成以下体验判断：

1. 能否在 30 秒内找到一条记忆当前状态、证据和 revision；
2. 能否分辨“归档”“隔离”“永久删除”各自会发生什么；
3. 在连接故障、无权和原文已清理时，页面有没有说清楚且没有装作知道；
4. 是否始终明白“关窗确认和修正仍回到与 hide 的对话”；
5. 桌面和手机上是否都像共同的“窝”，而不是运维后台或模板化 AI 产品；
6. 若任一不可逆动作的影响仍需第二次解释，则 HDM-023 不通过。
7. 能否清楚区分“详情中的证据预览”“完整保存证据”和“整场原对话”。
