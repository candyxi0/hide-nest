# nest console HTML prototype

这是治理控制台的高保真交互原型，不是生产前端。

## 打开

直接双击 `index.html`，或在本目录运行：

```powershell
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## 可体验流程

- 记忆列表搜索／筛选／切换详情；
- 展开最小充分证据与变化轨迹；
- 归档、隔离、隔离恢复预览；
- 永久删除影响预览、一次最终确认和 Run；
- ReviewSession 队列与“返回对话”；
- Run 阶段时间线；
- 系统状态；
- 原型状态切换：正常、加载、空、无权、过期、故障；
- 桌面与窄屏布局。

## 安全说明

- 所有内容均为合成示例；
- 不连接远端、不读取真实记忆；
- 不保存 Token、正文或搜索词；
- “复制对话指令”只写入剪贴板；
- 原型状态刷新后重置。

## 设计母题

“会呼吸的档案馆”：暖纸色、墨色排印、档案索引、时间脊线，以及克制出现的粉色生命标记。避免通用圆角 Dashboard、emoji、紫色科技渐变和黑客终端风。
