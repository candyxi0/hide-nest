## 4. 设计冻结点

- 关窗与修正回到 Codex 对话，不在网页复制第二套编辑器；
- React 本地 SPA 由 CodexAdapter loopback 托管，浏览器不持远端凭据；
- 原文仅显示服务端授权的最小必要证据片段；允许完整阅读该记忆已经保存的证据，但不提供整场原对话或完整原文库浏览；
- 不可逆动作不做虚假乐观完成；规范保存与索引就绪分开表达；
- 视觉保持温暖档案馆，不改成通用后台、黑色终端或卡通宠物界面；
- 精确依赖版本留给 CandidateManifest 的真实构建验证。
