## 原缺口与修法

原 `fail()` 在标记任一尝试失败后，直接依任务 generation 把整张任务改为 `RETRY_WAIT` 或 `ATTENTION_REQUIRED`。A1 租约过期、A2 已接管且仍持有效租约时，A1 的迟到失败会阻止 A2 续租，或提前产生告知。

现先在任务行锁下将该尝试标记 `FAILED`，再检查同任务是否仍有租约有效的 `RUNNING` 尝试。有则保留任务 `ATTEMPTING`，不生成告知；没有才按剩余预算进入重试或告知。续租也取得同一任务行锁，使它与失败、领取和结算判定按事务顺序收束。沿用现有端口的 `RETRY_WAIT` 返回值表示该失败尚未使任务终结；有有效兄弟时数据库任务状态仍是 `ATTEMPTING`。

未改变过期尝试争夺空结算槽、B 的前序阻塞、processed 围栏、规范提交或告知去重语义；未修改 SQL migration 或 runtime 端口。
