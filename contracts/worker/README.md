# Internal Core↔Cognitive Worker contract v1

These four JSON Schemas describe internal messages, not a public API or generated client. `contractVersion` and `outputContractVersion` are fixed to `nest.worker.v1`. Every object is closed to unknown fields. Core must validate the complete task/result pair, not only each message in isolation: `contractVersion`, `taskRef`, `worldRef`, `taskKind`, and lease `generation` must match; Retrieval additionally matches `targetTurnRef` and `inputVersion`. A stale or mismatched result must not be published.

Retrieval starts from bounded, actual `CURRENT_USER_TURN` text. Optional nearby messages and explicitly maintained anchors are also actual materials, not a generated summary. `sourceExclusion` names source/version/cursor ranges; `deliveredRevisionRefs` names already-delivered Memory revisions. Worker may query only its derived `cognitive_index` for candidate refs and navigation metadata. Core batch-resolves candidates against world, current state, governance, version, and readable scope before any resolved material reaches an Agent or reranker. `selected` is a Worker→Core selection result, not a complete contribution to the main model. Failed Retrieval never carries selected material or candidate half-products.

Formation's `sourceWorkRef` is an opaque, bounded Core-runtime work reference. Core binds it to source identity, progress range, version or short-term snapshot read policy; `READ_SOURCE` may dereference only that bound range. A chat `sessionRef` is optional and does not locate the source. One `WRITE_SET` item can cite multiple precise `sourceAnchors`, each with source identity, independent source version, and locator. Core must verify world, source version, Anchor frame/speaker/scope, and expected-current before its formal write entry accepts a proposal. Worker claims alone confer no authority. `SOURCE_INCOMPLETE`, `FAILED`, and `BUDGET_EXHAUSTED` cannot advance a source cursor; the result contract exposes no cursor-advance action. `NO_LONG_TERM_CHANGE` carries neither Evidence body nor a recallable negative conclusion.

Index Projection is derived state. Its generation, manifests, idempotency key, and watermark do not authorize it to decide current, governance, or durable meaning. Agent tool access is bounded to the named Core read capabilities and result submission; the contract grants no arbitrary SQL, shell, URL, filesystem, or database tool. The schemas do not prove candidate relevance, source truth, Core resolution, or any runtime lease/write behavior; those checks are `NOT_APPLICABLE` to this offline contract fixture set.
